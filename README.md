# EV Driver UX Framework

A UX strategy exploration focused on electric vehicle user experience, telemetry dashboards, charging workflows, and driver decision-support interaction design.

## Focus Areas

- Battery confidence UX
- Charging workflow optimization
- Driver distraction minimization
- Telemetry dashboard hierarchy
- Range anxiety reduction
- Alert prioritization
- Journey interruption handling
- Human-centered EV interaction design

## Context

Created as part of ongoing product design exploration in connected mobility, automotive HMI, and energy-aware digital ecosystems.
